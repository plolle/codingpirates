# codingpirates

Undervisningsmateriale til Coding Pirates.

## Kurser

- **[GDevelop — byg dit eget platformspil](gdevelop/)** — lav et platformspil fra bunden i
  GDevelop. Ti lektioner fra tomt projekt til færdigt spil med fjender, liv og flere baner.
- **[GDevelop — byg dit eget rumspil](rumspil/)** — et rumskib, der skyder asteroider og
  fjender i bølger, med eksplosioner, lyd og en highscore, der bliver gemt. Tag gerne
  platformspillet først. *Lektionerne er på vej.*
